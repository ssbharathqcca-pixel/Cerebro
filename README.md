# Cerebro

Human-controlled knowledge system and canonical repository for ROI OS context.

## Start here

1. Read `AGENTS.md` for the operating contract.
2. Read `STATE.md` for current verified state.
3. Load only the relevant sections of `Memory.md`, `DECISIONS.md`, `RISKS.md`, or `EVALS.md`.
4. Use `ChatGPT-Sync.md` when publishing or reconciling context across Cerebro, ChatGPT, and Codex.

## Authority

```text
verified artifact / Git / test / runtime / primary source
> current project documentation
> current task context
> durable Memory.md
> historical memory
```

`Memory.md` is the portable cross-project bootstrap. It is not a substitute for current repository evidence.
